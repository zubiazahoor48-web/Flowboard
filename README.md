Flowboard – Task Board

A Kanban-style task board that runs entirely in the browser. Create tasks, set priorities and due dates, and drag them across To do, In progress and Done. No backend or build step needed.

Features


Create, edit and delete tasks with title, notes, priority and due date
Drag and drop between columns (native HTML5 Drag and Drop)
Keyboard-friendly alternative: move buttons on every card
Overdue tasks highlighted automatically
Search and priority filter
Progress summary and per-column counts
"Clear done" action and sample data for a quick demo
Data saved in the browser with localStorage
Responsive dark UI, visible focus states, reduced-motion support


Tech stack


HTML5
JavaScript (ES6+, no framework)
Bootstrap 5 for components (modal, forms, buttons, toast)
Tailwind CSS (CDN) for layout utilities, with preflight disabled so it does not conflict with Bootstrap
